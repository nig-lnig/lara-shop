21. L’interface : gabarits, composants et JavaScript

Gabarits et morceaux partagés

  • resources/views/layouts/app.blade.php : bandeau supérieur, en-tête (logo, recherche, favoris, compte, panier), barre des familles, messages, contenu, pied de page.
  • resources/views/layouts/admin.blade.php : barre latérale de l’administration et zone de contenu.
  • resources/views/partials/flash.blade.php : messages de succès et d’erreur ; pour les erreurs de validation, un résumé dont chaque ligne est un lien vers le champ concerné (le message détaillé reste sous le champ).
  • resources/views/partials/totals.blade.php : sous-total, remise et total, utilisé par le panier, la commande et le détail des commandes.
  • resources/views/partials/account-nav.blade.php : onglets Mes commandes, Mes données, Favoris, Profil.
  • resources/views/errors/ : pages 403, 404, 419, 429 et 500 en français ; la page 403 affiche le message donné par abort(403, '…').

Composants

ComposantRôle
<x-input>, <x-select>Champ avec son étiquette, la valeur précédente (old()) et son message d’erreur.
<x-password-field>Mot de passe avec bouton afficher/masquer et liste des règles cochée en direct.
<x-add-to-cart>Formulaire d’ajout au panier, avec ou sans sélecteur de quantité.
<x-favorite-button>Cœur (cartes) ou bouton texte (fiche produit).
<x-product-image>Image du produit et tuile de famille si elle manque.
<x-stock-badge>, <x-status-badge>Badges de stock et de statut de commande.
<x-export-formats>Trois boutons CSV · Excel · PDF pour un jeu de données.
<x-icon>Petites icônes SVG.

Le JavaScript, toujours facultatif

public/js/app.js améliore l’expérience sans être nécessaire : sans lui, chaque formulaire et chaque lien fonctionne normalement. Ses sections : menus (compte, administration), panneau des filtres sur téléphone (focus déplacé dans le panneau, Échap pour fermer), sélecteurs de quantité et envoi automatique, ajout au panier et favoris sans rechargement (avec fetch), aperçu d’image, champs mot de passe, confirmations et bouton de commande désactivé après le premier clic.

Les animations sont courtes et désactivées (ou remplacées par un simple fondu) quand le système demande moins de mouvement (prefers-reduced-motion). Le style se trouve dans un seul fichier, public/css/app.css, organisé en sections numérotées, avec les couleurs en variables CSS (--ink, --cobalt…).

23. Écarts et comportements observés

Ce que fait réellement le code, là où il diffère d’une attente possible ou du sujet initial :

  • Livraison : le bandeau supérieur affiche « Livraison partout au Maroc », mais l’application ne gère ni frais, ni zones, ni transporteur : c’est un texte de présentation. Les commandes ont seulement un statut de suivi.
  • Paiement : aucun paiement en ligne. La condition (LIV ou T30) est enregistrée avec la commande, comme dans le sujet.
  • Client archivé : il disparaît des listes de l’administration, mais rien n’empêche son compte de se connecter et de commander.
  • Comptes de démonstration : leur mot de passe password ne respecte pas la politique des mots de passe ; le seeder écrit directement en base, sans passer par la validation.
  • Contrôles réseau : la vérification du domaine de l’e-mail (DNS) est désactivée par défaut ; la vérification des mots de passe divulgués (haveibeenpwned.com) est active mais ignorée sans Internet.
  • Verrouillage : lockForUpdate() agit sous MySQL ; avec SQLite, la base entière est verrouillée pendant une écriture, ce qui sérialise aussi les commandes.
  • Images : les photos de démonstration sont des illustrations SVG générées ; l’administrateur peut les remplacer par de vraies photos.
  • Bandeau d’accueil : affiché seulement sur la première page du catalogue sans filtre.
  • Page d’accueil : / est le catalogue ; l’ancienne adresse /catalogue redirige vers /.
  • Devise : dirham (DH), modifiable par SHOP_CURRENCY.
  • Codes métier : générés à partir de l’id ; après suppression d’une ligne, son numéro n’est jamais réutilisé.

24. Glossaire

Artisan
L’outil en ligne de commande de Laravel (php artisan serve, migrate, route:list, test).
Blade
Le langage de gabarits de Laravel : {{ $variable }} affiche une valeur (échappée contre le HTML), @if, @foreach, @csrf…
Cast
Conversion automatique d’une colonne : 'unit_price' => 'decimal:2', 'is_listed' => 'boolean', 'password' => 'hashed'.
Clé étrangère (FK)
Colonne qui contient l’id d’une ligne d’une autre table.
Clé primaire (PK)
Colonne qui identifie chaque ligne d’une table, ici id.
Composer
Gestionnaire des bibliothèques PHP (composer.json, dossier vendor/).
Contrôleur
Classe qui reçoit une requête, utilise les modèles et renvoie une vue, une redirection ou un fichier.
CSRF
Cross-Site Request Forgery : attaque qui fait envoyer un formulaire à votre insu ; bloquée par le jeton @csrf.
DECIMAL
Type SQL à virgule fixe (ici 10 chiffres dont 2 décimales), adapté aux montants.
Eloquent
L’ORM de Laravel : chaque table est manipulée par une classe modèle.
Flash
Valeur gardée en session pour la requête suivante seulement (message de confirmation).
Hachage
Transformation à sens unique d’un mot de passe (bcrypt) ; on compare, on ne déchiffre jamais.
Idempotent
Qui produit le même résultat si on le répète : envoyer deux fois la même commande n’en crée qu’une.
Liaison de modèle
Laravel transforme un paramètre d’adresse en objet modèle ({product:code}).
Middleware
Filtre placé devant les routes (connexion obligatoire, rôle, limitation de débit…).
Migration
Fichier de création ou de modification de table, versionné avec le code.
Modèle
Classe qui représente une table et ses relations (Product, Order…).
N+1
Problème de performance : une requête par élément d’une liste ; évité avec with().
Pivot
Table de liaison d’une relation plusieurs-à-plusieurs (favorites).
Policy
Classe d’autorisation liée à un modèle (OrderPolicy).
Portée (scope)
Condition de requête réutilisable déclarée dans un modèle (scopeAvailable).
Redirection
Réponse 302 qui demande au navigateur d’ouvrir une autre adresse.
Route
Association entre une méthode HTTP + une adresse et le code qui répond.
Seeder
Classe qui remplit la base avec des données de départ.
Service
Classe qui regroupe une logique métier (Cart, OrderService, PriceCalculator).
Session
Données gardées côté serveur pour un navigateur, identifié par un cookie.
Transaction
Groupe d’écritures validées ensemble ou annulées ensemble.
Trait
Bloc de méthodes PHP partagé par plusieurs classes (HasBusinessCode, Archivable).
Validation
Contrôle des données reçues avant de les utiliser.
Vue
Fichier Blade qui produit le HTML.
